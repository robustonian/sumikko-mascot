# 見本のキャラクターの透過 PNG

アプリが読み込む 5 枚です。すべて 1469×1071 の同じ座標に合わせて重ねます（寸法が数 px 違っても、描画時にこの大きさへ揃えます）。

| PNG | 内容 | 使われ方 |
| --- | --- | --- |
| `base.png` | 胴体、襟、リボン、机、キーボード。腕や頭に隠れる部分も描いてある | 下地。奥の腕の付け根を隠すために、胴体の一部をもう一度上に描く |
| `keyboard-arm.png` | 奥の腕（袖と手） | 根元／袖／袖口の縁／手 に切り分ける。袖は根元を固定して傾け、手は形を保って移動・回転・拡大する |
| `mouse-arm.png` | 手前の腕とマウス | 肩より上は固定、袖は手に付いて傾き、手首より下（手とマウス）は形を保って動く |
| `head.png` | 頭（髪、顔、髪飾り） | 首の付け根を中心に回し、下へ動かす。突き出た髪（アホ毛）は切り出して揺らす |
| `face-expression.png` | 目を閉じて口を開けた頭 | 目と口の範囲だけを使う。まばたき、口パク、笑顔（閉じ目＋開いた口）、寝顔（閉じ目）、あくび（閉じ目＋縦に伸ばした口） |

重ね順は、下地 → 奥の腕 → 下地の胴体（襟から右身頃の外側の輪郭まで）→ 手前の腕 → クリックの線 → 首 → 頭 → 目・口 → 記号、です。

この見本に固有の事情:

- `head.png` にあごの下の短い首が含まれているので、首だけを切り抜いて元の位置に固定し、頭はそれを除いて動かしています。そのため頭は上へは動かせません。新しく作る素材では、首を最初から `base.png` 側に付けます。
- `mouse-arm.png` の肩先に輪郭のない部分があるので、そこを切り落として輪郭線を描き足しています。
- `head.png` と `face-expression.png` は、輪郭全体が 1px ほど違います。頭まるごとの入れ替えはせず、目の範囲を縁をぼかして合成しています。

口をすぼめる動きと記号（zzz・！・ハートなど）は、画像を使わずにコードで描いています。

座標や切り分けの線は、このフォルダの `character.txt` にあります（同じ値が `../app/CharacterProfile.cs` にも初期値として入っています）。追加のキャラクターは `../characters/<名前>/` に、同じ 5 枚と `character.txt` を置きます。別のキャラクターで素材を作る手順は `parts-reference/README.md`、それを組み立てる手順は `../AGENTS.md` です。
