# 見本のキャラクターのもとになった絵

`desktop-companion-concept-v3.png` は、同梱している見本のキャラクターの完成図（キー画像）です。
`assets/` の透過 PNG 5 枚は、この 1 枚から切り分けて作りました。

- 構図: 上半身＋机＋キーボード・マウスを、斜め前から見る。手前の手はマウス、奥の手はキーボードに置く。
- 作り方: 利用者が用意したキャラクターの絵をもとに、画像生成で描いたもの。指示文の全文は `concept-v3-prompt.txt`。

自分のキャラクターで作るときは、この絵ではなく `../assets/parts-reference/` の参考シートと指示文を使います（手順は同フォルダの `README.md`）。
