# 使い方

[トップへ戻る](../README.md) · [English](en/usage.md)

## 起動

`Start.cmd` をダブルクリックします。

- 初回と、更新でソースが変わったあとは、Windows 標準の C# コンパイラでビルドしてから起動します（数秒）。.NET Framework 4 系が入っている Windows で動きます（動作確認は Windows 11 のみ。Windows 10 は未確認です）。
- 起動すると画面の右下に現れ、手を振ってあいさつします。
- 二重起動はしません。Windows の自動起動には登録しません。
- 終了は、キャラか通知領域のアイコンを右クリックして「終了」です。

## 操作

キャラを右クリックしても、通知領域のキャラの顔のアイコンを右クリックしても、同じメニューが開きます。
クリック透過中や非表示中でも、通知領域からすべての設定を変更できます。

| 操作 | 内容 |
| --- | --- |
| キャラを左ドラッグ | 表示位置を移動 |
| キャラの頭の上でポインターを左右に往復 | なでなで（クリック透過中でも反応します） |
| 音声 → オフ / マイク・仮想入力 / PC 再生 | 口パクの入力元を切り替え（起動時はオフ） |
| 音声 → オーディオデバイス設定… | デバイスの選択、音量の確認、口パクの感度 |
| 音声 → 口パクテスト（音声不要） | 音声を使わず、口の開閉だけを繰り返して確認 |
| 動き → キーボードの動きの大きさ | 控えめ / 大きく（標準） / とても大きく |
| 動き → 動きを抑える | 全体の動きを控えめにし、しぐさを止める |
| 動き → マウスの移動範囲… | キャラの手元のマウスが動く範囲を 4 方向で調整 |
| 動き → 動きの細かい調整… | しぐさのオン・オフや、動きの数値をスライダーで調整 |
| 動き → デモ | 自動の打鍵とクリックによる動作見本 |
| 表示 → 小 / 中 / 大 | 表示幅 320 / 440 / 560 |
| 表示 → クリック透過 | クリックを下のウィンドウへ通す。Ctrl+Alt+C でも切り替え |
| 表示 → 画面内に戻す | 位置を見失ったとき、ポインターのある画面の右下へ戻す |
| キャラクター → （名前） | 表示するキャラクターを切り替える（[キャラクターを切り替える](characters.md#キャラクターを切り替える)） |
| キャラクター → キャラクターのフォルダを開く | キャラクターを置く `characters` フォルダを開く |
| 一時的に隠す / 表示する | 会議や画面共有のときに隠す。隠している間は描画・入力の監視・音声の取得をすべて止める |
| 通知領域のアイコンをダブルクリック | 表示して、クリック透過を解除する |

Ctrl+Alt+C をほかのアプリが使っていて登録できなかったときは、メニューにその旨を表示します。透過の解除は通知領域のアイコンのダブルクリックでできます。

## 動き

- **キーボード**: キーを押すたびに、奥の手がキーボード上の毎回違う場所へ跳んで叩きます（押したキーの位置とは無関係です）。手は振り上げると大きくなり、叩きつけた瞬間に横へつぶれて跳ね返ります。手首は遅れて返り、頭が沈んで傾きます。
- **Enter**: ひときわ大きく叩き、目をぎゅっとつぶり、絵全体が沈んで跳ね返ります。
- **長押し**: 約 0.4 秒後から同じ場所を高速で連打し続けます。離すと止まります。
- **マウス**: 手元が素早く追いかけ、少し行き過ぎてから止まります。素早く横に動かすと手首に遅れて傾きます。上下・左右は、向かい合うキャラ側の向きに合わせて反転しています。
- **クリック**: 手元がぎゅっとつぶれて跳ね返り、マウスから短い線が 3 本飛び出します。
- **待機**: 頭がゆっくり揺れ、ポインターの側へ少し傾き、ときどき首をかしげます。まばたきは間隔も速さも不規則で、2〜3 回続くこともあります。
- **口元**: 打鍵中はきゅっとすぼめます。
- **アホ毛**: 頭の動きに遅れてしなり、止まると揺り戻します。

修飾キー（Shift・Ctrl・Alt など）だけでは叩きません。

## しぐさ

キーやクリックへの反応とは別に、キャラが自分から見せる動きです。

| しぐさ | きっかけ | 内容 |
| --- | --- | --- |
| あいさつ | 起動した時、隠した状態から戻った時 | 笑顔で手を振る。キーを打つとすぐやめる |
| 居眠り | 何もしない時間が続く（初期値は 2 分） | 大きなあくびで目じりに涙 → 重いまばたきを 3 回 → 眠る。こっくりと沈んでは跳ね起き、z が立ちのぼる |
| 起きる | 眠っている時に何かする | キー・クリック・声・勢いよくマウスを動かす: 「！」と一緒にびくっと跳ね起きる。マウスをそっと動かす: 静かに目を開ける。置いたマウスのわずかな震えでは起きない |
| やりきった | 続けて 20 打以上打ったあとの Enter | 手を高く掲げたまま満面の笑顔。きらきらが弾ける（12 秒は続けて出ない） |
| なでなで | 頭の上でポインターを左右に 2 回以上折り返す | 目を細めて口を開け、手に合わせて頭を揺らし、ハートを浮かべる。通り過ぎるだけでは反応しない |
| 考え中 | 打つ手が止まって 2〜3 秒 | ときどき首をかしげて「…」を浮かべ、指でトントンと叩く |
| 必死の汗 | とても速い打鍵（毎秒 7 打以上）が続く | 汗が飛ぶ |

しぐさは **動き → 動きの細かい調整…** の「しぐさ」タブで 1 つずつオン・オフできます。
「動きを抑える」をオンにすると、しぐさは一切出ません。マウスの移動範囲を調整している間も出ません。

## 口パク（音声）

メニューの **音声 → オーディオデバイス設定…** で、口パクに使う音声とデバイスを選び、「保存して適用」を押します。

- **マイク・仮想入力**: マイクや、録音デバイスとして登録されている仮想オーディオ。仮想ケーブルは、その録音側を選びます。
- **PC 再生**: スピーカー・ヘッドホン・仮想出力など、音が再生されているデバイス。音楽や効果音にも反応します。
- **Windows の既定**: 既定のデバイスを使います。既定を変えたときは、音声を一度オフにして選び直してください。
- 各デバイスの横の「試す」で、音量と口の開き方をメーターで確かめられます（試すだけでは保存も切り替えもしません）。
- **感度** と **小さい音を無視** を調整できます。反応しないときは感度を上げ、ずっと口が開くときは無視する音量を上げます。
- デバイスは名前ではなく ID で保存します。選んだ機器が未接続でも選択を保ち、別の機器へ勝手には切り替えません。
- 起動時の音声は常にオフです。入力元を選ぶと、保存したデバイスで始まります。

口パクは音量に応じた開閉です（母音の識別はしません）。排他モードで再生している音には反応しないことがあります。
**音声 → 口パクテスト（音声不要）** で、音を使わずに小・中・大の開口を確かめられます。

## 動きの細かい調整

メニューの **動き → 動きの細かい調整…** で、しぐさのオン・オフと、動きの数値を変えられます。

- タブは「しぐさ」「キーボードの手」「マウスの手」「頭」「まばたき・口」の 5 つ、項目は約 50 個です（振り上げの高さ、着地のつぶれ、追いかける速さ、クリックの線の長さ、アホ毛の揺れ、まばたきの間隔、居眠りまでの時間、記号の大きさ、Enter で机が揺れる大きさ など）。
- 確定やキャンセルはありません。動かした瞬間にキャラへ反映され、少し後に自動で保存されます。画面を開いたまま、いつもどおりキーを打ったりクリックしたりして確かめられます。
- 「デモを流す」をオンにすると、自動の打鍵とクリックを見ながら調整できます。
- 初期値から変えた項目は太字になります。「戻す」でその項目だけ、「すべて初期値に戻す」で全部を戻せます。
- 「変えた値をコピー」で、変えた値の一覧をクリップボードへコピーします。
- クリックの線を出したくないときは「マウスの手 → クリックの線の長さ」を、記号を出したくないときは「しぐさ → 記号の大きさ」を 0 にします。

## マウスの移動範囲

メニューの **動き → マウスの移動範囲…** で、キャラの手元にあるマウスをどこからどこまで動かすかを決めます。PC のカーソルの動く範囲は変わりません。

- 上 → 下 → 左 → 右を 1 方向ずつ合わせます。方向は、あなたがマウスを動かす向きです。
- 絵の中をクリックして案内された方向へマウスを動かすと、キャラの手もその操作に付いてきます。一番遠くまで試した位置を覚えます。絵の外へ出る、Space を押す、別のウィンドウへ移ると計測を止めます。
- 「端の位置で止めて調整」やスライダー、「－ 小さく」「大きく ＋」、矢印キーで到達位置を整えます。
- 「この方向で決定」で次へ、「戻る」で前へ。上部の方向の名前をクリックすると、その方向へ直接移れます。
- 「この方向を初期値に戻す」「開いた時の値に戻す」で、その方向だけを戻せます。
- 4 方向目の「保存して完了」で保存します。「キャンセル」または × は調整前に戻します。

## 設定の保存と軽さ

- 位置・サイズ・動きの強さ・マウスの範囲・選んだ音声デバイス・口パクの感度は `bin/settings.txt` に、「動きの細かい調整」で変えた値は `bin/tuning.txt` に保存します。どちらもこの PC の中だけのファイルです。
- 見本以外のキャラクターを選んでいるときは、どのキャラクターを選んだかと、そのキャラクター用のマウスの範囲も `bin/settings.txt` に、動きの細かい調整は `bin/tuning-<フォルダ名>.txt` に保存します（キャラクターごとに別々です）。
- 保存は一時ファイルに書き終えてから置き換えるので、途中で失敗しても前の設定は残ります。
- 保存に失敗したとき、起動時に設定を読み込めなかったときは、お知らせとメニューの先頭の項目で知らせます（もう一度保存する／設定を読み込み直す／現在の設定で上書き保存）。読み込めなかった設定を勝手に上書きすることはありません。
- 何も起きていない間は描画を毎秒約 30 回に落とし、見た目が同じフレームは描き直しません。キー・クリック・速いマウス移動・口パクのときは、そのフレームから画面のリフレッシュレートに戻します。眠っている間も毎秒約 30 回です。
- 「一時的に隠す」の間は、描画・入力の監視・音声の取得をすべて止めます。

## プライバシー

- キーは「押された」ことと、Enter かどうか、押しっぱなしかどうかだけを見ています。**どのキーを押したか、何を入力したかは記録しません**。
- 音声は音量だけを使います。録音・保存はしません。
- ネットワーク通信はしません。
- 保存するのは上の設定ファイルだけです。
