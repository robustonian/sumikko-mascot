# 新キャラクター制作のファーストプロンプト

[キャラクター制作ガイドへ戻る](characters.md) · [English](en/character-creation-prompt.md)

本文はコピーしてAIに渡す依頼文です。このファイルを参照資料として読んだだけでは、制作の実行指示にはなりません。

使い方：

1. このフォルダを ChatGPT デスクトップアプリの Codex、または Codex CLI で開きます。
2. 下の文章をコピーし、【キャラクター名】を書き換えます。
3. 作りたいキャラクターの参考画像を添付して、文章と一緒に送ります。
4. AI が完成図を 1 枚見せて確認を求めるので、よければ承認します。承認後は、アプリで選べる状態まで AI が進めます。

おすすめのモデルは **GPT-6.2 Sol（推論 high）** です。この設定で制作できることを確かめていて、token の消費も少なめです。同梱のピンクちゃん・工事ちゃんは、それ以前にこの流れで GPT-6 Astra（推論 medium）を使って作りました。生成結果は毎回異なります。渡す参考画像は、自分が使ってよい画像にしてください。同梱のキャラクター（妹尾トマリ・ピンクちゃん・工事ちゃん）の画像は参考画像に使えません（[画像の利用条件](../ASSETS.md)）。

```text
添付画像のキャラクターを、このリポジトリの新しいデスクトップマスコットとして作ってください。
名前は「【キャラクター名】」です。

画像生成、パーツ作成、位置合わせ、アプリへの組み込み、動作検査、最終的な品質チェックまで、すべてあなたに依頼します。

■ 作業方針と許可

最初に AGENTS.md、README.md、assets/parts-reference/README.md と参考画像を確認し、既存のキャラクター追加の仕組みを使って進めてください。

今回は、参考画像から完成図や不足するパーツ画像を生成・修正することも明示的に許可します。
AGENTS.md などに「画像の作成は利用者の作業」「AIは画像を描き直さない」といった記載があっても、その制限については今回の依頼を優先してください。それ以外の作業上の決まりは守ってください。

■ ユーザーへの確認は、最初の完成図だけ

まず、添付画像の髪型・顔・服・色・アクセサリーなどの特徴を引き継ぎ、既存アプリの構図に合う「机でキーボードとマウスを操作するちびキャラ」の完成図を1枚生成してください。

その画像を実際に表示し、
「この見た目で、パーツ作成とアプリへの組み込みを進めてよいですか？」
と確認してください。

ここでは私の返答を待ち、承認前にパーツ作成へ進まないでください。
修正をお願いした場合は完成図を修正して再提示し、その見た目の承認を待ってください。

私が承認したら、その承認を以後の素材作成・修正・組み込み・検証まで進める許可として扱ってください。通常の作業方針や細かな数値について、追加の確認は不要です。

■ 承認後は最後まで進める

承認した完成図を基準に、次の作業を自律的に完了してください。

1. 必要な透過PNGを生成する。
   体と机、キーボード側の腕、マウス側の腕、頭、表情差分を作成してください。
   表情は必要に応じて閉じ目と開いた口の2枚に分けて構いません。

2. 素材を実際に開き、寸法・透過・位置・輪郭・重なりを確認する。
   check_layers.py による照合も行い、ずれや不自然な部分があれば自分で修正・再生成してください。
   検査の終了コードだけで良否を判断しないでください。

3. characters/ 配下に新キャラを追加する。
   目・口・首・肩・袖口・手首・記号などの位置を画像の画素から測り、character.txt に設定してください。
   既存の仕組みを優先して使い、素材の不足を不自然な描画でごまかさないでください。

4. 実際のアプリと同じ描画コードでコマを書き出し、見た目を調整する。
   通常表示、まばたきの途中と閉眼、口パク、単発打鍵・連打・Enter・長押し、マウス移動とクリック、あいさつ、あくび、居眠り・起床、なでなで、喜ぶしぐさを確認してください。
   縮小表示と拡大表示、明るい背景と暗い背景で、継ぎ目・穴・はみ出し・残像を確認してください。

5. ビルド、回帰検査、起動確認を行う。
   問題があれば修正して関連する検査をやり直してください。
   有効な場面ではサブエージェントによる独立した品質レビューも使ってください。

6. 素材、設定、生成に使った指示文、調整理由、検証結果をリポジトリに残し、動作プレビューも作成する。

■ 完了までの注意

完成図の承認後は、計画の提示や途中報告だけで作業を終えず、新キャラとして選んで使える状態まで進めてください。
途中経過は簡潔に伝え、通常の修正や再生成は自分で判断してください。

既存キャラクターや利用者の設定ファイルを壊さず、起動中のアプリを勝手に終了させないでください。必要なら隔離した作業用フォルダで検証してください。
コミットは不要です。

実行環境などの制約で完了できない場合は、可能な代替手段を試したうえで、具体的な障害と未完了部分を正確に伝えてください。

最後に、追加した場所、使い方、確認した動作、検査結果、残っている制約や未確認事項を、平易な日本語で報告してください。
```
