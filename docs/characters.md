# キャラクターの追加と切り替え

[トップへ戻る](../README.md)

## 自分のキャラクターで作る

参考画像からの制作をまとめてAIに依頼する場合は、[キャラクター制作の依頼文](character-creation-prompt.md)を使ってください。完成図の承認後にパーツ生成・組み込み・検証まで進める手順です。画像生成とフォルダ内の作業ができる環境（ChatGPT デスクトップアプリの Codex、Codex CLI など）が必要です。

自分でパーツを用意する場合は、次の3段階で進めます。

1. **元になる絵を 1 枚用意する**。作りたいキャラクターの絵です（頭身や構図は問いません）。
2. **画像生成でパーツを作る**。[assets/parts-reference/README.md](../assets/parts-reference/README.md) の手順どおりに、参考シート `parts-sheet.png` と用意してある指示文を画像生成 AI に渡します。できあがるのは、見本と同じ構図のキー画像 1 枚と、透過 PNG 5 枚です。

   | ファイル | 内容 |
   | --- | --- |
   | `base.png` | 胴体・首・机・キーボード |
   | `keyboard-arm.png` | 奥の腕（袖と手） |
   | `mouse-arm.png` | 手前の腕とマウス |
   | `head.png` | 頭（首なし） |
   | `face-expression.png` | 目を閉じて口を開けた頭（まばたき・口パク・笑顔・寝顔・あくびに使う） |

   必須はこの 5 枚だけです。この 5 枚で、上に書いた動きとしぐさがすべて動きます。
3. **AI に渡して組み立てる**。このリポジトリを Codex（ChatGPT デスクトップアプリ・Codex CLI）や Claude Code などのコーディング AI で開き、キー画像と 5 枚を置いたフォルダを伝えて「このキャラクターで組み立てて」と頼みます。AI は [AGENTS.md](../AGENTS.md) の手順に沿って、画像の確認、位置合わせ、ビルド、検査、動きの見た目の確認までを行います。できあがったキャラクターは `characters/<名前>/` に入り、メニューの「キャラクター」から選べるようになります。見本のキャラクターはそのまま残ります。

知っておいてほしいこと:

- 位置合わせ（目・口・手首・肩などの座標）は、キャラクターごとの設定ファイル `character.txt` に書きます。AI が絵を測って書き込みます。項目の一覧と説明は、見本の [assets/character.txt](../assets/character.txt) にあります。
- 追加キャラクターの制作・検証例は、[ピンクちゃん](../characters/pink-chan/README.md)と[工事ちゃん](../characters/koji-chan/README.md)にあります。生成結果によって位置合わせや画像の作り直しが必要です。
- 見本のキャラクターの絵（`assets/` と `design/`）は見本として同梱しています。

### キャラクターを切り替える

- メニューの「キャラクター」に、見本と、`characters` フォルダにあるキャラクターが並びます。選ぶとその場で切り替わり、次の起動でも同じキャラクターが出ます。
- キャラクター 1 人分は、`characters/<好きなフォルダ名>/` に置いた透過 PNG 5 枚と `character.txt` です。5 枚がそろっていないフォルダはメニューに出ません。`face-expression.png` の代わりに、閉じ目の頭 `eyes-closed.png` と開いた口の頭 `mouth-open.png` の 2 枚に分けて置くこともできます。
- 同梱のキャラクター: 見本（`assets/`）、[ピンクちゃん](../characters/pink-chan/README.md)（`characters/pink-chan/`）、[工事ちゃん](../characters/koji-chan/README.md)（`characters/koji-chan/`）。
- メニューに出る名前は `character.txt` の `name = …` です（書いていなければフォルダ名）。
- `character.txt` に書かなかった項目は見本の値が使われます。読めない行があった場合は、切り替えた時にどの項目かを知らせ、その項目は見本の値で表示します。
- マウスの移動範囲と動きの細かい調整は、キャラクターごとに別々に覚えます。「マウスの移動範囲」や「動きの細かい調整」の画面を開いている間は切り替えられません。
- 通知領域のアイコンも、選んだキャラクターの顔になります。
