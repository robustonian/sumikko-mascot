# ピンクちゃん

利用者から渡された 参考画像 をもとに、ピンクのツインテール、黒いリボン、銀色の髪留め、白・黒・ピンクのジャケットを残して作った追加キャラクターです。

`Start.cmd` でアプリを起動し、右クリック → **キャラクター → ピンクちゃん** で選べます。起動中に追加した場合は、アプリを一度終了して起動し直してください。

![アプリの描画コードで書き出したピンクちゃん](preview.png)

## 素材と調整

- `key.png`: 生成した完成図。位置照合用で、アプリには表示しません。
- `base.png` / `keyboard-arm.png` / `mouse-arm.png` / `head.png`: 体・机、奥の腕、手前の腕とマウス、頭。
- `eyes-closed.png` / `mouth-open.png`: 閉じ目と開いた口の差分。アプリは目・口の範囲だけを使います。
- `character.txt`: この絵に合わせて画素を測った設定。
- `generation-prompts.json`: 内蔵 `image_gen` で使用した指示文と、各ファイルに採用した生成結果の対応。素材生成から組み込みまで担当することについて、利用者の明示的な許可を得て制作しました。

座標はアプリが使う1469×1071で測っています。生成PNGの寸法は1501×1048、1502×1047、1519×1036で、既存の読み込み処理で揃います。元の生成PNGは再加工せず保存しました。

主な調整は次のとおりです。

| 場所 | 測定・設定 |
| --- | --- |
| 首 | 体側の首を上方へ延長。頭の回転中心 `(599,644)`、上昇上限8px |
| 目 | 開いた目・閉じ目の画素から多角形を設定。まつ毛の欠片が残らない閉じ目素材を作り、曲線のまぶたを使用 |
| 口 | 開口範囲の中心 `(719,555)`、半径 `(33,28)`、上唇の基準 `(719,536)` |
| 奥の手首 | 境界の円を測定し、中心 `(955,801)`、半径約63px。測定点と円の誤差RMSは約0.49px |
| 奥の袖 | 付け根 `(737,729)`、袖口方向 `(-0.300,0.954)`。打鍵・あいさつで袖が細くなりすぎない動きに調整 |
| 手前の腕 | 肩の固定線696、手首の線887。輪郭の補修は不要 |
| マウス | 範囲は左右 `-90〜45`、上下 `-35〜0`。下端がキャンバスに近いため下方向は固定 |
| 記号 | 頭の右の空間 `(1010,245)` を基準に表示 |

ツインテールやリボンは頭と一緒に動きます。別々に揺らすための分離素材は作っていないため、アホ毛の独立変形は無効です。

## 確認結果（2026-11-17）

- `check_layers.py`: 必要な6枚の存在・透過を確認、終了コード0。完成図との差は **4.59%**。標準キャンバスとの縦横比警告は出ます。髪先や補完した袖・肩などには生成時の描き直し差があり、完成図との画素単位の完全一致ではありません。正規化後の合成とアプリの描画を目視確認しました。
- `verify.ps1`: **298項目すべて合格**。新キャラの設定読み込み問題は0件。既存キャラを含む回帰検査とプレビュー出力も成功。
- `build.ps1`: 成功。
- 起動検査: 同じ実行ファイルと素材を隔離した作業フォルダへ複製し、`character=pink-chan` で `--smoke-test --demo` を実行。**4.01秒後に終了コード0**、終了後もピンクちゃんが選択された状態を確認。
- 利用者の `bin/settings.txt` と `bin/tuning*.txt` は変更していません。起動検査の前後でファイルのSHA-256が一致しました。
- 見た目: まばたき0.1刻み、閉眼保持、口パク0〜1、すぼめ口、単発・連打・Enter・長押し、強い動き、四隅までのマウス移動とクリック、あいさつ、あくび、居眠り・起床、なでなで、やりきったのしぐさを、縮小図と拡大図で確認。明るい背景と暗い背景の両方も確認しました。別担当も顔・首・肩・袖口と記号を独立して確認しました。

まばたき途中は既存の描画方式による簡略化したまぶたです。短く通過する途中コマでは、元の太いまつ毛との形の違いが見えます。実際のキー・マウス操作でのテンポや好み、異なる画面倍率での印象は、利用者の環境でも確認してください。音声入力機器を使う口パクの実機検査は行っていません。
