# motion-harness（見た目の確認ツール）

アプリと同じ描画コード（`app/CharacterView.cs`）で、キャラのポーズやコマ送りを PNG に書き出す開発用ツールです。
実機を動かさずに、動きの見た目や数値の推移を確認できます。アプリ本体の動作には関係しません。

## ビルド

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/motion-harness/build-harness.ps1 -root <プロジェクトのフォルダ> -scratch <Harness.cs のあるフォルダ>
```

`-scratch` に指定したフォルダに `Harness.exe` ができます。作業用フォルダへ `Harness.cs` をコピーしてから指定すると、リポジトリを汚しません。

## 使い方

```
Harness.exe <プロジェクト> <出力先> <モード> <指定> [強度] [フラグ]
```

| モード | 指定 | 内容 |
| --- | --- | --- |
| `pose` | `"名前:x:y:lift:flick;..."` | キーボード側の手を指定の姿勢で止めて書き出す |
| `face` | `"名前:フィールド=値,...;..." [強度] [neck]` | 顔を書き出す（6 番目の引数があれば首まわり）。`blink` / `purse` / `headY` / `nod` / `headAngle` など |
| `hold` | `x [強度]` | 1 打のあと長押し。高さの推移を表示し、コマを書き出す |
| `blinks` | `x` | 60 秒間のまばたき開始時刻を表示 |
| `idle` | `x [強度]` | 待機 24 秒＋Enter 1 回。2 コマおきに全体を半分の大きさで保存し、`head.csv` も出力 |
| `mouse` | `x` | マウスの素早い移動とクリック 150 コマ（マウス範囲は -65 / 115 / -82 / 8 に固定） |
| `sim` | `"秒数;時刻:?;時刻:?:?:1;..." 強度 [--frames] [--demo] [--full]` | 打鍵シナリオ（4 番目が 1 なら Enter 扱い）。`trace.csv` を出力 |
| `scene` | `"秒数;時刻:命令[:引数];..." [何コマおき] [x,y,幅,高さ] [縮尺]` | しぐさを含む場面。`scene.csv`（頭・手・目・口・机の沈み・記号の数・アホ毛）も出力 |

`scene` の命令: `k` キー、`e` Enter、`c` クリック、`h:秒` 長押し、`p:x:y` 画面上のポインター（-1〜1）、`a:x:y` 絵の上のポインター（`a:off` で不明）、`g` あいさつ、`set:キー=値` 調整値、`reduced:0|1` 動きを抑える、`strength:値` 動きの大きさ。
例（20 秒で眠る設定にして、36 秒でキーを押して起こす）: `scene "40;0.1:set:act.sleepAfter=20;36:k" 6 150,0,1100,640 .32`

`scene` 以外のモードは、しぐさを切った「素の動き」で動かします（`--scenes` を付けると有効）。どのモードでも、引数に `set:キー=値` を並べると調整値を指定できます（例: `set:hair.ahoge=0` でアホ毛を止める）。

引数に `--character=<フォルダ名>` を付けると、`assets/` の見本の代わりに `characters/<フォルダ名>/` のキャラクターを描きます。`character.txt` に読めない行があれば標準エラーに出します。

## 補助スクリプト（Python + Pillow）

- `sheet.py <出力> <列数> <画像...>`: コマを 1 枚に並べ、各コマにファイル名を入れる。
- `plot.py <trace.csv> <出力> <イベント指定> <開始秒> <終了秒>`: `sim` の軌跡（lift / x / y / flick / nod）をグラフにする。

## 動画にするとき

ffmpeg を使います。Windows 版では `-pattern_type glob` が使えないため、コマを連番に並べ直して `-start_number 1 -i s%04d.png` のように渡してください。
書き出した画像や動画は `preview/` に置きます（git では管理しません）。全コマの書き出しには 1〜2 分かかります。
